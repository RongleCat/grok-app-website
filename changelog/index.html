更新日志

近几版稳定更新

开源 Grok App 是本机 Grok Build CLI 的桌面 GUI。下面是最近几个稳定版。也有人搜 Grok Desktop、Grok GUI 或桌面客户端。

  1. v0.2.30

    2026-09-01

    设置里可从本地装插件，推荐里可一键加 X API。

    • 设置 → 插件可从本地文件夹或 git 安装；带 MCP 的会出现在扩展。
    • 推荐插件新增 X API，可在 MCP 列表授权。
    • 更多界面语言补上文案；后台 git / worktree 不再堵其它命令。
    • 思考结束后会画出正文，不用切走再切回来。

  2. v0.2.29

    2026-08-30

    一键装 CLI、翻译补全、长对话更顺。

    • 找不到 Grok Build CLI 时，运行时设置可一键安装。
    • 补上缺的翻译（SSH、权限、Doctor 等）。
    • 长会话滚动更顺，每帧少做全量扫描。
    • 回退后用户那句会回到输入框；流式输出时对话不再乱跳。

  3. v0.2.28

    2026-08-28

    SSH 远端主机、模型推理合一芯片，对话跟住输出。

    • 设置里可 Watch SSH 远端主机，并在远端文件夹开新对话。
    • 输入框改为一颗模型 + 推理芯片。
    • 对话跟住流式输出；最后几行不再压在输入框上。
    • Windows 更新后任务栏保留 Grok 图标。

  4. v0.2.27

    2026-08-27

    设置页透明度、斜杠选插件、对话公式，提问不再挡住会话。

    • 设置页可调节不透明度（外观 → 主题）。
    • 斜杠菜单可以选整个插件包；仍可只选其中一条 skill。
    • 对话支持 LaTeX 公式，与 Grok Build CLI 一致。
    • 计划卡片和 Agent 提问不再挡住会话。

  5. v0.2.26

    2026-08-24

    导入 CLI 会话、同一 Wi-Fi 手机镜像，Windows 点击与长对话滚动修复。

    • 可导入 CLI 会话；自动加项目按相对 home 深度判断。
    • 手机镜像可允许同一 Wi-Fi 访问（应用内确认后绑定局域网）。
    • 修复 Windows 权限卡点击无响应、回退确认窗关不掉。
    • 长会话上下浏览不再卡死。
