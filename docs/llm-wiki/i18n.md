# 站点语言（i18n）

官网必须同时提供 **简体中文、繁體中文、English**。  
用户可见字符串禁止写死在组件里，一律走 key。

## 语言 ID

| id | 名称 | `html lang` |
|----|------|-------------|
| `zh` | 简体中文 | `zh-CN` |
| `zh-TW` | 繁體中文 | `zh-TW` |
| `en` | English | `en` |

三份目录 **同一套 key**。缺键视为 bug，不能只在一种语言里出现新文案。

权威文案表：[content.md](./content.md)。`en` 与 `zh` / `zh-TW` 在同一 PR 填齐。

## 解析顺序（硬性）

存储键：`localStorage["grok-app-site.locale"]`  
合法值：`system` | `zh` | `zh-TW` | `en`

```text
1. 若存储值是 zh / zh-TW / en  → 用它（用户手动切换过）
2. 若无存储，或值为 system     → 跟系统
3. 系统无法判断                 → en
```

「跟系统」读 `navigator.languages`（优先）再 `navigator.language`：

| 标签前缀 / 形态 | 映射 |
|-----------------|------|
| `zh-TW` / `zh-Hant` / `zh-HK` / `zh-MO` | `zh-TW` |
| `zh` / `zh-CN` / `zh-Hans` / `zh-SG` | `zh` |
| 以 `en` 开头 | `en` |
| 其他 | `en` |

监听 `languagechange`：**仅当**当前偏好仍是 `system`（或尚未手动选过）时重算。用户已锁定某语言则忽略系统变化。

首次访问不要预写 `zh`。应写 `system` 或不写，让解析走系统。  
用户点语言切换器后，写入具体 id（`zh` / `zh-TW` / `en`），不再跟系统，直到用户选「跟随系统」（若 UI 提供）。

## UI

效果图 header 右侧是主题三点 + 「免费下载」，没有语言控件。实现必须加，且不能破坏胶囊导航与主题点的构图：

- 放在顶栏左侧 Logo「Grok App」右侧。
- 形态：纯文字 `简 / 繁 / EN`，当前语言加粗。不要圆形按钮或原生 `<select>`。
- 切换后整页文案立即替换，无需刷新。同步 `document.documentElement.lang`。
- 工作台截图里的 App UI（SuperGrok、侧栏中文）保持截图像素，不随站点语言重绘。

## 实现约定

建议：

```text
src/i18n/zh.ts
src/i18n/zh-TW.ts
src/i18n/en.ts
src/i18n/index.ts    # t / resolveLocale / resolveLocaleFromSystem
```

- `t(locale, key)`；变量用 `{name}`。
- 产品名 `Grok`、`Grok App`、`Grok Build`、`SuperGrok` 不翻译。
- 下载包格式名 `AppImage` / `DEB` / `RPM` / `Apple Silicon` / `Intel` 可保留。
- 禁止 `locale === "zh" ? "下载" : "Download"` 分叉。

实现：`src/i18n/{index,catalog,zh,zh-TW,en}.ts`，启动时 `src/main.ts` 填 `data-i18n`。首屏 `title` / `description` / `html lang` 由各页 HTML 内联脚本按同一算法写入，不预写 `zh`。`main.ts` 按路径区分首页 / `/opensource/` / `/faq/` / `/skins/` / `/install/` / `/changelog/` 的 title 与 description key。GitHub 按钮 star 短语是 `github.stars`（`{count}`），切语言时 `syncGithubStars` 重写 `aria-label`，见 [stars.md](./stars.md)。
