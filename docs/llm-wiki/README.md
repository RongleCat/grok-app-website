## 原则

1. **可检索**：一条知识一个文件，标题即意图。
2. **可执行**：写路径、文件名、URL、禁止事项，不写空泛建议。
3. **现在时**：Wiki 描述的是仓库此刻的状态，不是愿望清单。
4. **变更同步**：改代码必改 wiki；改 wiki 后实现要跟上。
5. **跨 Agent**：后续 Agent 只认本目录，不靠会话记忆。
