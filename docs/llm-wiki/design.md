# 落地页设计

视觉权威：[assets/landing-dark.png](./assets/landing-dark.png)。

**必须完整还原效果图。** 不是「神似」，不是换一套流行模板再塞文案。桌面宽度下：区块顺序、对齐、胶囊导航、双 CTA、窗口截图比例、三枚浮动胶囊位置、卡片圆角与密度、皮肤四宫格、开源横条、底部三下载钮，都要能和效果图并排对照。

禁止：Inter + 紫渐变、通用 AI SaaS、居中巨大描边字、彩虹光斑、与效果图无关的插画。

亮色主题是**同构适配**（同一骨架、同一组件、换 token + 换工作台截图），不是另做一页。细则见 [theme.md](./theme.md)。文案三语见 [content.md](./content.md)。语言见 [i18n.md](./i18n.md)。

## 页面骨架（自上而下）

| 4 | `capabilities` `#features` | 胶囊标题「更强大的能力，更自由的生产力」+ 六张能力卡 |

## Hero

- 居中排版。主标题里 **Grok** 用衬线/对比字重，其余无衬线。
- 双 CTA：实心浅色「免费下载」（带下载图标）；描边「GitHub 开源」。
- 工作台预览是一张 **macOS 窗口框**（红黄绿灯 + 侧栏 + SuperGrok HEAVY 空状态）。
- 暗色站点主题用 [workbench-dark.png](./assets/workbench-dark.png)；亮色站点主题用 [workbench-light.png](./assets/workbench-light.png)。
- 三枚浮动胶囊贴在窗口周围，不要嵌进截图像素里：
  - 左上：多模型支持 · Grok 4.6 及更多模型
  - 右上：快速响应 · 平均响应 1.2s（数字若无测量依据，实现时改为不写死毫秒，或放到 Wiki 后再改文案）
  - 左下：数据安全 · 本地优先，隐私可控

「平均响应 1.2s」来自效果图，产品仓未提供公开基准。落地时**先不要写死 1.2s**，改成「快速响应 / 本机直连 Grok Build」，除非用户确认保留该数字。回写 content.md。

- 下载 macOS · Apple Silicon / Intel

## 完整还原（桌面）

对照宽度：**1440× 与 1280×**。把实现截图与 `landing-dark.png` 叠看。

必须对齐：

1. 顶栏：Logo 左、导航绝对居中胶囊、右侧控件不把导航挤歪。
2. Hero 主标题字号与字重对比（「Grok」可衬线/对比），副标题更弱、更小。
3. 双 CTA：实心浅钮 + 描边深钮，圆角胶囊，中间空隙与效果图同级。
4. 窗口预览：大圆角、细边、可识别的交通灯；截图不被裁成细条。
5. 三枚浮动胶囊：左上 / 右上 / 左下，半透明深底 + 细边，不挡窗口主体。
6. Section 标题本身是小胶囊，居中，不是左对齐大标题。
7. 价值三卡一行；能力六卡 3×2；皮肤四卡一行，选中带勾。
8. 开源条通栏深卡，左图标+文案，右按钮。
9. 下载三钮横排，系统图标 + 主副行文字。
10. 页脚单行弱文字，不做成第二套导航巨无霸。

偏差只允许：语言切换器（效果图没有，产品要求必须有）；版权年 2026；速度胶囊不写 1.2s。其它偏差先改实现，不要改效果图。

## 窄屏 / 移动端（必须美，不能只是缩小）

断点（实现用 CSS，不要 JS 探测布局）：

| 名称 | 宽度 | 原则 |
|------|------|------|
| desktop | `≥1280px` | 完整还原效果图 |
| laptop | `1024–1279px` | 同骨架，略减左右 padding；浮动胶囊可内收，仍不挡标题 |
| tablet | `720–1023px` | 价值卡改 1 列或叠放；能力 2 列；皮肤 2×2。**768 及以下顶栏**改汉堡 + 次行语言/主题，下载 CTA `nowrap`，避免桌面顶栏把「免费下载」挤成竖排 |
| mobile | `≤719px` | 见下表，按「重排不是压缩」 |

### mobile 重排

| 区块 | 行为 |
|------|------|
| header | Logo + 下载缩小钮 + 汉堡（或「菜单」胶囊）。语言与主题进菜单或顶栏次行，不换行挤爆。汉堡三杠收在按钮中心（`align-content: center` + 4px 间距），不要被 44px 格子撑开。 |
| 胶囊导航 | 收入汉堡下方的下拉（`.nav-cluster` 相对定位，菜单 `top: calc(100% + 8px); right: 0`），不要在页面正中展开。菜单项仍是站点风格。 |
| Hero 文案 | 全宽，标题允许 2–3 行，不要字号小到像注释。 |
| 双 CTA | 可全宽叠放，主钮在上。 |
| 窗口截图 | 全宽，保持圆角与边框；左右不要被裁掉侧栏。 |
| 浮动胶囊 | **禁止叠在截图上挡内容**。改到截图下方横滑或三枚竖叠，间距均匀。 |
| 价值 / 能力卡 | 单列，卡之间留足空隙，图标与标题不挤成一行蚂蚁字。 |
| 皮肤 | 横向 snap 滚动或 2×2，选中态仍可见。 |
| 开源条 | 改为上文本、下按钮，按钮不要贴边裁切。 |
| 下载三钮 | 单列全宽，主副文案仍在，点击热区 ≥44px。 |
| 页脚 | 可折行，链接换行后仍可点。 |

### 窄屏审美

- 仍用同一套 token 与圆角，不要 mobil 时突然变成扁平白卡片。
- 安全区：`env(safe-area-inset-*)`。
- 不要横向整页滚动（皮肤条内部横滑可以）。
- 触控：点击目标至少 44×44。
- 动效减弱：`prefers-reduced-motion`。
- 暗色下文字对比足够；亮色下边框仍能看见卡片边界。

验收宽度至少拍：`1440`、`1280`、`1024`、`768`、`390`。`390` 与 `768` 不得出现重叠、裁字、横溢、胶囊压在 SuperGrok 标题上。

独立开源页：`/opensource/`。含仓库地址与介绍、作者铁柱 AGI（X + 公众号 / 添加微信好友二维码弹窗）、以及 Issues 投稿的贡献者墙（当前 8 人，数据 `src/generated/contributors.json`，名单见 [contributors.md](./contributors.md)）。`oss.wall.body` 与卡片网格之间有 28px 间隔。卡片链到投稿留下的主页。明暗主题与落地页共用 token。

二维码弹窗：`#qr-dialog`。公众号图 `public/images/wechat/mp-search-scan.png`（产品仓 README 搜一搜图）；好友码 `public/images/wechat/community-group-qr.png`（产品仓 `assets/wechat/` 第二张个人码，按钮文案按用户要求写成添加好友）。

## 已实现 / 与效果图的已知偏差

实现入口：`index.html` + `src/styles/*.css`。桌面构图按上表十条对齐。

允许的偏差（产品要求，不是漏做）：

1. 顶栏增加文字语言切换 `简 / 繁 / EN`（在 Logo 右侧，不是圆形按钮）；主题改为月亮/太阳图标，不用效果图三圆点。
2. 页脚版权年 **2026**，不抄效果图 2024。
3. 速度胶囊文案为 `pill.speed.desc`（本机直连 Grok Build），不写 1.2s。
4. 主标题里的 **Grok** 与全站英文用非衬线，不用衬线对比字。
5. 顶栏 Logo 用产品仓 `IconGrokMark` 路径（`public/logo.svg`），不是效果图上的简化 G。
6. 顶栏内容包在 `--max` 内左右分布，不再贴视口左右边。

其它：皮肤绿/琥珀两张是同一张暗色工作台加滤镜示意，不是产品仓独立截图。隐私 / 条款链到 GitHub，本站尚无独立法律页。
